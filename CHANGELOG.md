## [0.1.0] - 2026-09-18

### Added

- Local MCP server for configuring, listing, searching, and reading Notability exports.
- Text extraction for TXT, Markdown, RTF, and HTML exports.
- Local file links for PDF, Note, ZIP, image, and audio exports.
- Configured-root path confinement and text scan limits.
- Codex plugin skill and marketplace metadata.
- Cross-platform tests and GitHub Actions CI.
